# 标准字符集

这些 `.cst` 文件来自原版 FontMaker 1.2.0 发布包，作为格式兼容性资产保留。

格式：原始 UTF-16LE 码元流，无文件头、无结束符。文件顺序就是字库输出顺序。

| 文件 | 字符数 | 说明 |
|---|---:|---|
| `ASCII.cst` | 96 | U+0020–U+007F |
| `GB2312-8K.cst` | 8192 | 8K 精简表 |
| `GB2312.cst` | 8836 | GB2312 顺序 |
| `GBK.cst` | 24066 | GBK 顺序 |
| `UNICODE.cst` | 65536 | 全部 BMP 码元，代理项按 U+FFFD 输出 |
| `ISO8859-1.cst` | 256 | Latin-1 |
| `IBM860.cst` | 256 | OEM 葡萄牙语 |
| `KOI8-R.cst` | 256 | 俄语 |

加载 `.cst` 时按“16 位码元”处理，不把相邻代理项合成为补充平面字符。需要 emoji 等非 BMP 字符时，请使用“用户定义”的 UTF-8 文本。
