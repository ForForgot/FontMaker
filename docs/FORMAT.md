# FontMaker 数据格式

本文档描述 2.0 版本仍然兼容的字符集、C 数组和 BIN 布局。

## 1. `.cst` 字符集

- 原始 **UTF-16LE** 码元流
- 无文件头
- 无字符数
- 无结束符
- 文件顺序即输出顺序
- 文件开头如果是 `FF FE`（UTF-16LE BOM），读取时跳过
- 奇数字节会被拒绝
- 按“UTF-16 码元”而不是“Unicode 文本”处理：每个 16 位单元保留一个输出记录
- 代理项单元不配对，统一变为 `U+FFFD`；因此 `UNICODE.cst` 仍有 65536 个记录
- 如需完整支持 emoji 等补充平面字符，请使用“用户定义”的 UTF-8 文本

例如 `ASCII.cst` 的前几个字节：

```text
20 00 21 00 22 00 ...
```

对应 `U+0020`、`U+0021`、`U+0022`。

### 自定义码表

“用户定义”模式接受 UTF-8 文本，内部解码为 Unicode 码点。文本编辑器的“载入/保存”也使用 UTF-8，无 BOM。

## 2. 点阵单元

渲染器始终返回固定 `width × height` 的单元。`coverage` 中任意非零像素视为点亮。

字体高度使用 GDI 的正 `lfHeight`，即字符单元高度；实际字形可能小于单元，因此界面提供 X/Y 偏移。

## 3. 扫描和位序

### 横向扫描

逐行，从左到右；每 8 个横向像素打包成 1 字节。

```text
record size = height × ceil(width / 8)
```

### 纵向扫描

逐列，从上到下；每 8 个纵向像素打包成 1 字节。

```text
record size = width × ceil(height / 8)
```

### 位序

- `MSB`：字节最高位（bit 7）对应第一个像素
- `LSB`：字节最低位（bit 0）对应第一个像素
- 行/列末尾不足 8 位时补 0

## 4. 可变宽度

启用“可变宽度”后，每个字符记录前增加 2 字节：

```text
+--------+--------+----------------------+
| widthH | widthL |  pixel data ...      |
+--------+--------+----------------------+
```

- 大端序 16 位无符号 advance width
- 单位是像素
- 像素数据部分与固定宽度完全相同
- 不裁剪点阵矩阵

16×16 固定宽度为 32 字节，可变宽度为 34 字节。

## 5. C 数组

生成形式：

```c
static const unsigned char bits[][32] =
{
    { // U+0030 '0'
        0x00, 0x00, 0x00, 0x00, 0x00, 0x00, 0x00, 0x00,
        0x00, 0x00, 0x00, 0x00, 0x00, 0x00, 0x00, 0x00,
        0x00, 0x00, 0x00, 0x00, 0x00, 0x00, 0x00, 0x00,
        0x00, 0x00, 0x00, 0x00, 0x00, 0x00, 0x00, 0x00,
    },
    { // U+0031 '1'
        /* ... */
    },
};
```

- 外层维度由字符集决定
- 内层维度是固定记录长度
- 每个 glyph 前有 `U+XXXX`（非 BMP 为 `U+XXXXX`）注释
- 可打印字符会在注释中附带字符本身
- 注释使用 UTF-8；文件无 BOM
- C 数组不包含码点索引表；顺序由字符集决定

## 6. BIN 字库

所有记录直接拼接：

```text
glyph[0] | glyph[1] | glyph[2] | ...
```

没有：

- 文件头
- magic
- 字符总数
- 字符宽度/高度
- 扫描方向
- 位序
- 码表

这些参数由生成端和消费端约定。对于固定宽度 16×16 横向 MSB 的 `ASCII.cst`，BIN 大小是：

```text
96 × 32 = 3072 bytes
```

## 7. 兼容性说明

2.0 保持以下语义不变：

- 字符顺序
- 固定/可变宽度记录大小
- 扫描方向
- 位序
- 可变宽度前缀为 2 字节大端序
- C 数组的数据部分和 BIN 的拼接顺序

2.0 的 C 源码排版、注释和渲染 DIB 位深有变化，因此不承诺与 1.2.0 文本逐字节相同。
